PROYEK TERSIMPAN

Proyek disimpan di browser/perangkat ini. Gunakan ekspor cadangan untuk memindahkan proyek.

Panduan singkat

  1. Tambahkan satu atau beberapa foto.
  2. Atur durasi, gerakan, rasio dan judul video.
  3. Tulis narasi. Tombol dengarkan memakai suara Text-to-Speech yang tersedia di Windows/browser.
  4. Tambahkan musik bila diperlukan. Atur subtitle.
  5. Tekan Ekspor Video dan simpan hasilnya.
Catatan format: Ekspor dasar menghasilkan WebM langsung di perangkat. Ekspor MP4 memerlukan komponen FFmpeg WebAssembly yang diunduh saat pertama kali dipakai (perlu internet). Setelah komponen tersimpan di cache browser, penggunaan berikutnya dapat lebih mudah dilakukan offline. Narasi Text-to-Speech adalah pratinjau suara perangkat; untuk memasukkan suara narasi ke hasil video, rekam suara menjadi file audio lalu tambahkan melalui kolom Musik latar / audio.

Privasi dan penyimpanan

Foto dan proyek diproses di perangkat. Data proyek disimpan lokal dan tidak dikirim ke server. Simpan salinan cadangan JSON secara berkala.
